# dot 文档

## 当前规范

[`design-baseline.md`](design-baseline.md) 是当前唯一具有规范性的产品与行为契约。它规定用户
配置、公开命令、所有权、清理边界和明确接受的风险。

仓库根 [`README.md`](../README.md) 说明当前可用入口；代码、测试与 CI 是实现状态的证据。
[`../CONTRIBUTING.md`](../CONTRIBUTING.md) 规定变更分级、验证证据和 Git 交付流程。

## 历史恢复

[`archive/README.md`](archive/README.md) 只保存历史 Git 指针。历史内容没有规范性，不得作为
新增代码、兼容行为或日常工作流的依据。

## 文档原则

- 产品规则由明确的唯一 owner 维护，其他文档只链接，不复制定义。
- 内部 package、依赖方向和测试组织属于架构说明，不构成产品行为。
- 难以逆转且需要长期保留理由的选择使用 ADR；不为历史选择补写 ADR。
- 新能力或防御须由真实用户故事、已发生故障或不可接受的数据损失路径证明收益。
